Unidade 4 — Entrada e Saída por arquivos
Slides U4-01 a U4-36 · título: “4.1 – Funções para leitura e gravação de arquivos da biblioteca da linguagem C”
4.1 Abstração: fila de bytes, buffer e ponteiro de arquivo
Resumo das funções (U4-04, U4-05)
Tabela do professor: “A diferença entre os comandos” (U4-19)
Função Tipo mais comum O que faz
fprintf() Texto Grava dados formatados
fscanf() Texto Lê dados formatados
fwrite() Binário Grava bytes/blocos
fread() Binário Lê bytes/blocos
fputc() Texto/binário Grava 1 caractere/byte
fgetc() Texto/binário Lê 1 caractere/byte
📘  TEXTO DO SLIDE
Para tratar de arquivos a linguagem C fornece um nível de abstração entre o programador e o dispositivo
que estiver sendo usado. Esta abstração é chamada fila de bytes e o dispositivo normalmente é o arquivo.
Existe um sistema bufferizado de acesso ao arquivo, onde um ponteiro de arquivo define vários aspectos
do arquivo, como nome, status e posição corrente, além de ter a fila associada a ele. (U4-03, exemplo “entrada e
saida arquivo.cpp”)
💡  EXPLICAÇÃO
Você nunca fala direto com o disco. Você declara um FILE *fp (o “ponteiro de arquivo”) e todas as funções
(fprintf, fread...) recebem esse ponteiro. Ele guarda nome, status (aberto, erro, fim) e em que posição você
está. Os bytes passam por uma “fila” (stream) e por um buffer na memória.
🧩  EXEMPLO
Pense no FILE* como o marcador de página de um livro: ele sabe qual livro (nome), se o livro está aberto
(status) e em que página você parou (posição corrente).
📘  TEXTO DO SLIDE
fprintf: escrita em arquivos – trabalha bem com arquivos txt.
fwrite: escrita em arquivos – trabalha bem com arquivos binários (estruturas).
fscanf: leitura em arquivos – trabalha bem com arquivos txt.
fread: leitura em arquivos – trabalha bem com arquivos binários (estruturas).
fputc: escreve um byte/caractere por vez em arquivos txt.
fgetc: leitura de um byte por vez em arquivos txt.
FILE: tipo arquivo · fopen: função de abertura de arquivos · fclose: função de fechamento de arquivos.
fprintf(): funciona como a função printf(). A diferença é que a saída de fprintf() é um arquivo e não a tela
do computador. Protótipo: int fprintf (FILE *fp,char *str,...);

fopen e os modos de abertura (U4-07 a U4-10)
Modo Significado (texto do slide)
"r" Abre um arquivo texto para leitura. O arquivo deve existir antes de ser aberto.
"w" Abrir um arquivo texto para gravação. Se o arquivo não existir, ele será criado. Se já existir, o conteúdo
anterior será destruído.
"a" Abrir um arquivo texto para gravação. Os dados serão adicionados no fim do arquivo ("append"), se ele já
existir, ou um novo arquivo será criado, no caso de arquivo não existente anteriormente.
"rb" Abre um arquivo binário para leitura. Igual ao modo "r" anterior, só que o arquivo é binário.
"wb" Cria um arquivo binário para escrita, como no modo "w" anterior, só que o arquivo é binário.
"ab" Acrescenta dados binários no fim do arquivo, como no modo "a" anterior, só que o arquivo é binário.
"r+" Abre um arquivo texto para leitura e gravação. O arquivo deve existir e pode ser modificado.
"w+" Cria um arquivo texto para leitura e gravação. Se o arquivo existir, o conteúdo anterior será destruído. Se não
existir, será criado.
"a+" Abre um arquivo texto para gravação e leitura. Os dados serão adicionados no fim do arquivo se ele já
existir, ou um novo arquivo será criado, no caso de arquivo não existente anteriormente.
"r+b" Abre um arquivo binário para leitura e escrita. O mesmo que "r+" acima, só que o arquivo é binário.
"w+b" Cria um arquivo binário para leitura e escrita. O mesmo que "w+" acima, só que o arquivo é binário.
"a+b" Acrescenta dados ou cria um arquivo binário para leitura e escrita. O mesmo que "a+" acima, só que o
arquivo é binário.
⚠  CAI NA PROVA / PEGADINHA
Decore em pares: printf ↔ fprintf (texto, escreve), scanf ↔ fscanf (texto, lê), fwrite ↔ fread (binário,
struct), fputc ↔ fgetc (1 caractere). A prova costuma trocar “grava” por “lê” ou “texto” por “binário”. putc =
fputc e getc = fgetc (mesma função, U4-28).
📘  TEXTO DO SLIDE
fscanf: funciona como a função scanf(). A diferença é que fscanf() lê de um arquivo e não do teclado do
computador. Protótipo: int fscanf (FILE *fp,char *str,...);
Como já poderíamos esperar, a única diferença do protótipo de fscanf() para o de scanf() é a especificação
do arquivo destino através do ponteiro de arquivo.
📘  TEXTO DO SLIDE
fopen: esta é a função de abertura de arquivos. Seu protótipo é: FILE *fopen (char
*nome_do_arquivo,char *modo);
O nome_do_arquivo determina qual arquivo deverá ser aberto. Este nome deve ser válido no sistema
operacional que estiver sendo utilizado. O modo de abertura diz à função fopen() que tipo de uso você vai
fazer do arquivo.

fclose e o buffer (U4-11, U4-12)
💡  EXPLICAÇÃO
Regra para nunca errar: letra = intenção (r = read/ler, w = write/escrever do zero, a = append/acrescentar
no fim); + = também faz o contrário (lê e grava); b = binário. Só o r exige que o arquivo exista; w apaga o
que havia; a preserva e escreve no fim.
📘  TEXTO DO SLIDE
Poderíamos então, para abrir um arquivo binário para escrita, escrever:
FILE *fp;                 /* Declaração da estrutura */
fp=fopen ("exemplo.bin","wb"); // o arquivo se chama exemplo.bin e está no diretório corrente
if (!fp)
   printf ("Erro na abertura do arquivo.");
A condição !fp testa se o arquivo foi aberto com sucesso porque no caso de um erro a função fopen()
retorna um ponteiro nulo (NULL). Uma vez aberto um arquivo, vamos poder ler ou escrever nele
utilizando as funções que serão apresentadas.
🧩  EXEMPLO
Um app de anotações: ao salvar a nota inteira de novo use "w" (substitui); para um log de vendas do dia
use "a" (cada venda entra no fim, nada é apagado); para abrir o cadastro só para consultar use "r".
⚠  CAI NA PROVA / PEGADINHA
• “Abri com "w" um arquivo que já tinha dados” → os dados foram destruídos.
• “Abri com "r" um arquivo que não existe” → fopen retorna NULL (não cria!).
• if(!fp) e if(fp == NULL) são a mesma verificação.
• r+ × w+: os dois leem e gravam, mas r+ exige que exista e não apaga; w+ cria/apaga.
• a × w: ambos criam se não existir; a diferença é o que acontece se já existir.
📘  TEXTO DO SLIDE
Quando acabamos de usar um arquivo que abrimos, devemos fechá-lo. Para tanto usa-se a função fclose():
int fclose (FILE *fp);
O ponteiro fp passado à função fclose() determina o arquivo a ser fechado. A função retorna zero no caso
de sucesso.
Fechar um arquivo faz com que qualquer caracter que tenha permanecido no "buffer" associado ao
fluxo de saída seja gravado.
Mas, o que é este "buffer"? Quando você envia caracteres para serem gravados em um arquivo, estes
caracteres são armazenados temporariamente em uma área de memória (o "buffer") em vez de serem
escritos em disco imediatamente. Quando o "buffer" estiver cheio, seu conteúdo é escrito no disco de uma
vez.
A razão para se fazer isto tem a ver com a eficiência nas leituras e gravações de arquivos. Se, para cada
caracter que fôssemos gravar, tivéssemos que posicionar a cabeça de gravação em um ponto específico do
disco, apenas para gravar aquele caracter, as gravações seriam muito lentas. Assim estas gravações só serão
efetuadas quando houver um volume razoável de informações a serem gravadas ou quando o arquivo for
fechado.
A função exit() fecha todos os arquivos que um programa tiver aberto.

Lendo e escrevendo caracteres: putc / getc (U4-13, U4-18)
int main()
{  FILE *fp;  char string[100];  int i;
   fp = fopen("arquivo.txt","w");   /* Arquivo ASCII, para escrita */
   if(!fp)
   {  printf( "Erro na abertura do arquivo");  exit(0); }
   printf("Entre com a string a ser gravada no arquivo:");
   gets(string);
   for(i=0; string[i]; i++)
       putc(string[i], fp);      // Grava a string, caractere a caractere
   fclose(fp);
   return 0;
}
Arquivos binários com struct: fwrite e fread (U4-14 a U4-17)
🧩  EXEMPLO
O buffer é o carrinho do supermercado: em vez de ir ao caixa a cada produto (lento), você junta tudo e
passa de uma vez. O fclose é “ir ao caixa com o que sobrou no carrinho”. Esquecer o fclose = sair da loja
deixando produtos no carrinho (dados podem não ser gravados).
📘  TEXTO DO SLIDE
putc: a função putc é utilizada na escrita de arquivo. Seu protótipo é: int putc (int ch,FILE *fp);
escreve um caractere no arquivo.
O programa a seguir lê uma string do teclado e escreve-a, caractere por caractere em um arquivo em
disco (o arquivo.txt, que será aberto no diretório corrente).
💡  EXPLICAÇÃO
O laço for(i=0; string[i]; i++) para quando string[i] vale '\0' (zero = falso). É o jeito “C” de percorrer
uma string até o terminador nulo.
📘  TEXTO DO SLIDE
“Escrevendo em Arquivos binários”, “Lendo em Arquivos binários”, “Fwrite, Fread em arquivos binários”,
“Escrevendo e lendo em arquivos binários – laço for”. O mesmo programa aparece em 3 slides: uma struct
Aluno (codigo, nome[50], nota) é gravada em "alunos.bin" com "wb" e depois lida com "rb".

typedef struct { int codigo; char nome[50]; float nota; } Aluno;
int main() {
  FILE *arquivo;
  Aluno alunos[3] = { {1,"Joao",8.5}, {2,"Pedro",9.0}, {3,"Jose",5.0} };
  Aluno alunosLidos[3];  int i;
  // ===== ESCREVER NO ARQUIVO =====
  arquivo = fopen("alunos.bin", "wb");
  if (arquivo == NULL) { printf("Erro ao abrir o arquivo.\n"); return 1; }
  for (i = 0; i < 3; i++)
      fwrite(&alunos[i], sizeof(Aluno), 1, arquivo);
  fclose(arquivo);
  printf("Dados gravados com sucesso!\n");
  // ===== LER DO ARQUIVO =====
  arquivo = fopen("alunos.bin", "rb");
  if (arquivo == NULL) { printf("Erro ao abrir o arquivo.\n"); return 1; }
  for (i = 0; i < 3; i++)
      fread(&alunosLidos[i], sizeof(Aluno), 1, arquivo);
  fclose(arquivo);
  // ===== MOSTRAR OS DADOS =====
  for (i = 0; i < 3; i++) {
      printf("\n########################\n");
      printf("Codigo: %d\n", alunosLidos[i].codigo);
      printf("Nome: %s\n",   alunosLidos[i].nome);
      printf("Nota: %.2f\n", alunosLidos[i].nota);
  }
  return 0;
}
💡  EXPLICAÇÃO
fwrite(endereço, tamanho_de_cada_item, quantidade, arquivo) e fread(endereço, tamanho,
quantidade, arquivo) têm a mesma ordem de parâmetros. Na versão dos slides U4-14/15/16 o professor
usa variáveis soltas (aluno1, aluno2, aluno3 gravadas; aluno4, aluno5, aluno6 recebem a leitura) e no U4-17
troca por vetor + laço for. A leitura sai na mesma ordem em que foi gravada: aluno4 recebe os dados de
aluno1 (Joao, 8.50), aluno5 os de aluno2 (Pedro, 9.00), aluno6 os de aluno3 (José, 5.00).
⚠  CAI NA PROVA / PEGADINHA
• fwrite(&aluno1, sizeof(Aluno), 1, arquivo) — o 1º argumento é endereço (&), o 2º é o tamanho
(sizeof), o 3º é a quantidade de itens.
• Gravar com "wb" e ler com "rb". Abrir binário com "r"/"w" é o tipo de “erro” que vira alternativa.
• typedef struct {...} Aluno; permite escrever Aluno a; sem a palavra struct.

5.1 Funções — definição (U5-03)
Estrutura das funções de usuário (U5-04 a U5-07)
📘  TEXTO DO SLIDE
Funções (também chamadas de rotinas, ou sub-programas) são a essência da programação
estruturada. Funções são segmentos de programa que executam uma determinada tarefa específica.
Exemplos: sqrt(), getch().
É possível ao programador escrever suas próprias rotinas que são as funções de usuário ou rotinas de
usuário, podendo segmentar um programa grande em vários programas menores (modularização) e
permite que cada segmento seja escrito, testado e revisado individualmente sem alterar o
funcionamento do programa como um todo.
A modularização também permite que um programa seja escrito por vários programadores ao mesmo
tempo, cada um escrevendo um segmento separado.
🧩  EXEMPLO
Um app de delivery: uma pessoa escreve calcularFrete(), outra aplicarCupom(), outra emitirNota().
Cada função é testada sozinha e o main só chama na ordem certa — isso é modularização.
⚠  CAI NA PROVA / PEGADINHA
Funções de biblioteca (já prontas: sqrt, getch, printf, pow) × funções de usuário (você escreve: media2,
soma). Vantagens citadas: dividir o programa, testar/revisar separadamente, vários programadores ao
mesmo tempo.
📘  TEXTO DO SLIDE
Uma função de usuário constitui-se de um bloco de instruções que definem os procedimentos efetuados
pela função, um nome pelo qual a chamamos e uma lista de argumentos passados à função.
float media2(float a, float b)
{  float med;
   med = (a + b) / 2.0;
   return(med);
}
A função chamada media2 recebe dois argumentos tipo float: a e b. A média destes dois valores é calculada
e armazenada na variável med declarada internamente. A função retorna um valor do tipo float (o valor
da variável med) para o programa que a chamou. O retorno desse valor é feito pela função return() que
termina a execução da função.
De modo formal, a sintaxe de uma função é: tipo_de_retorno nome_da_função(tipo_1 arg_1, tipo_2
arg_2, ...) { [bloco de instruções da função] }
A primeira linha da função contém a declaração da função. Na declaração de uma função se define o
nome da função, seu tipo de retorno e a lista de argumentos que recebe. Em seguida, dentro de chaves
{}, definimos o bloco de instruções da função.

argumentos.

📘  TEXTO DO SLIDE
Corpo da função escrito em arquivo separado: em C é permitido que o usuário crie uma função em um
arquivo e um programa que a chame em outro arquivo distinto. Esta facilidade permite a criação de
bibliotecas de usuário: um conjunto de arquivos contendo funções escritas pelo usuário. Esta possibilidade
é uma grande vantagem utilizada em larga escala por programadores profissionais.
Devemos incluir este arquivo no conjunto de arquivos de compilação do programa principal. Esta inclusão é
feita com a diretiva #include, que instrui o compilador para incluir na compilação do programa outros
arquivos que contêm a definição das funções de usuário e de biblioteca. Sintaxe: #include "path" — na
diretiva #include, indicamos entre aspas duplas o caminho de localização do arquivo onde está definida a
função chamada. Exemplo: #include "c:\tc\userbib\stat.h".
Observação: um arquivo pode conter a definição de uma ou mais funções. Em geral, quando o arquivo
possui apenas uma função ele é nomeado com o mesmo nome da função e extensão *.cpp ou *.c (ex.:
media.cpp). Quando um arquivo possui a definição de mais de uma função, ele é nomeado com a
extensão *.h ou *.lib (ex.: media(), dsvpd(), moda(), max(), min() em stat.h).
⚠  CAI NA PROVA / PEGADINHA
• #include <stdio.h> (sinais de menor/maior) = biblioteca do sistema; #include "stat.h" (aspas) =
arquivo do usuário com o caminho.
• Protótipo termina com ; e não tem corpo; pode ter só os tipos: float media2(float,float);
• 1 função → .c/.cpp com o nome da função; várias → .h ou .lib.
📘  TEXTO DO SLIDE
Sempre é possível que um programa principal chame uma função que por sua vez chame outra função e
assim sucessivamente. Quando isto acontece dizemos que a função chamadora tem hierarquia maior (ou
superior) à função chamada. Quando isto ocorre, devemos ter o cuidado de definir (ou incluir) as funções
em ordem crescente de hierarquia, isto é, uma função chamada é escrita antes de uma função
chamadora. Isto se deve ao fato de que o compilador deve conhecer uma função antes de que a
chamada seja compilada.
🧩  EXEMPLO

relatorio → main.

📘  TEXTO DO SLIDE
Em C, uma variável só pode ser usada após ser declarada. Isto porque o processador deve reservar um
local da memória para armazenar os valores atribuídos à variável. Porém o local, do programa, onde uma
variável é declarada define ainda seu escopo de validade. Uma variável pode ser local, global ou formal
de acordo com o local de declaração.
Locais: uma variável é dita local se for declarada dentro do bloco de uma função. Tem validade apenas
dentro do bloco onde é declarada (só pode ser acessada e modificada dentro do bloco). O espaço de
memória é criado quando a execução do bloco é iniciada e destruído quando encerrado. Assim,
variáveis de mesmo nome, mas declaradas em blocos distintos, são para todos os efeitos variáveis
distintas (ex.: med em media2() e med em main()).
Formais: uma variável formal é uma variável local declarada na lista de parâmetros de uma função. Tem
validade apenas dentro da função, porém serve de suporte para os valores passados pelas funções. As
variáveis formais na declaração da função e na chamada da função podem ter nomes distintos. A única
exigência é de que sejam do mesmo tipo. Por serem variáveis locais, os valores que uma função passa
para outra não são alterados pela função chamada — passagem por valor, pois os valores das variáveis do
programa chamador são copiados para as correspondentes variáveis da função chamada. (Ex.: a e b são
parâmetros formais de media2(); mesmo que a e b fossem alterados, num_1 e num_2 não seriam.)
Globais: uma variável é dita global se for declarada fora do bloco de uma função. Tem validade no escopo
de todas as funções (pode ser acessada e modificada por qualquer função). O espaço de memória é criado
no momento de sua declaração e destruído apenas quando o programa é encerrado.
📘  TEXTO DO SLIDE
No exemplo, a, b, med são variáveis globais definidas fora dos blocos das funções media() e main(). Deste
modo ambas as funções têm pleno acesso às variáveis. Assim não é necessária a passagem de
parâmetros para a função.
🧩  EXEMPLO
Global = quadro de avisos do condomínio (todo morador lê e pode riscar). Local = caderno dentro do
seu apartamento (só você vê; outro apartamento pode ter um caderno com o mesmo nome e é outro
caderno).

Quando são definidos parâmetros formais para uma função será preciso passar argumentos como

correspondente. Ou seja, o argumento é apenas um valor de entrada. Dessa forma, qualquer alteração
feita, dentro da função, no parâmetro não vai afetar o argumento do programa chamador, porque o
que está sendo manipulado dentro da função é uma cópia do argumento.

📘  TEXTO DO SLIDE
As regras que regem onde uma variável é válida chamam-se regras de escopo da variável. A regra de
escopo define o âmbito de validade de variáveis, ou seja, onde as variáveis e funções são reconhecidas.
• Duas variáveis globais não podem ter o mesmo nome. O mesmo vale para duas variáveis locais de
uma mesma função.
• Duas variáveis locais, de funções diferentes, podem ter o mesmo nome sem perigo algum de conflito,
pois sua existência será em blocos diferentes.
• Se uma função declarar uma variável local com o mesmo nome de uma variável global, esta variável
local ocultará/substituirá aquela global, que não poderá mais ser acessada (naquela função).

📘  TEXTO DO SLIDE
Recursão é o processo pelo qual uma função chama a si mesma repetidamente um número finito de
vezes. Este recurso é muito útil em alguns tipos de algoritmos chamados de algoritmos recursivos.
Exemplo clássico: fatorial. n! = n·(n-1)·(n-2)·...·3·2·1 e 0! = 1, onde n é inteiro positivo. Propriedade: n! =
n·(n-1)! — chamada de propriedade recursiva: o fatorial de um número pode ser calculado através do
fatorial de seu antecessor. Para criarmos uma rotina recursiva, em C, basta criar uma chamada à própria
função dentro dela mesma.
A principal vantagem: algumas classes de algoritmos [inteligência artificial, simulação numérica, busca e
ordenação em árvore binária, etc.] são mais facilmente implementadas com rotinas recursivas.
Enquanto n não for igual a 1, a função fatorial chama a si mesma, cada vez com um valor menor. O n==1 é
critério de parada. Há certos algoritmos que são mais eficientes quando feitos de maneira recursiva, mas a
recursividade é algo a ser evitado sempre que possível, pois, se usada incorretamente, tende a consumir
muita memória e ser lenta. Lembre-se que memória é consumida cada vez que o computador faz uma
chamada a uma função. Com funções recursivas a memória do computador pode se esgotar rapidamente.
📘  TEXTO DO SLIDE
Série de Fibonacci (U5-38): sequência formada pela soma de cada numeral com o numeral que o antecede.
No caso do 1, repete-se esse numeral e soma-se: 1 + 1 = 2; 2 + 1 = 3; 3 + 2 = 5; 5 + 3 = 8; 8 + 5 = 13; 13 +
8 = 21; 21 + 13 = 34; 34 + 21 = 55; 55 + 34 = 89 … numa sequência infinita.
⚠  CAI NA PROVA / PEGADINHA
• Toda recursão precisa de critério de parada; sem ele a função chama a si mesma até estourar a memória.
• Recursivo × iterativo: o recursivo é mais curto/elegante; o iterativo (for/while) gasta menos memória. O
slide diz que a recursividade deve ser evitada sempre que possível.
• No fatorial do slide em float (if (resposta<=1) return 1.0;) o critério é <=1, que também cobre 0! = 1.

6.1 Vetores — definição (U6-03 a U6-06)
📘  TEXTO DO SLIDE
Definição: um vetor é um conjunto de variáveis de um mesmo tipo de dado as quais são acessadas e
referenciadas através da posição de índices ao identificador do vetor.
Em muitas aplicações, quando queremos trabalhar com conjuntos de dados que são semelhantes em tipo,
seria conveniente colocar estas informações sob um mesmo conjunto (ex.: alturas dos alunos de uma turma:
float altura[7] = {1.80, 1.30, 1.48, 1.90, 1.73, 1.96, 1.76};).
Em programação, este tipo de estrutura de dados é chamada de vetor (ou array, em inglês) ou, de maneira
mais formal, estruturas de dados homogêneas. Os vetores são estruturas de dados estáticas, já que
permanecem do mesmo tamanho ao longo de toda a execução do programa. Um vetor em C é um
grupo de locais de memória relacionados pelo fato de que todos têm o mesmo nome e o mesmo
tipo.
A lista n/nota: 0→8.4, 1→6.9, 2→4.5, 3→4.6, 4→7.2. n representa um número de referência (índice) e nota é o
nome do conjunto: a 1ª nota é 8.4 → nota[0]=8.4; a 2ª nota é 6.9 → nota[1]=6.9.
Para reservar 10 elementos para o vetor de inteiros c: int c[10]; Para referência a um elemento: a =
c[5]; O primeiro elemento em qualquer vetor é o elemento zero: c[0]. O segundo é c[1]. Em geral, o i-
ésimo elemento do vetor c é chamado c[i-1]. Os nomes dos vetores seguem as mesmas convenções dos
nomes de outras variáveis (c2, resposta, notasIntProg).
🧩  EXEMPLO
Fileira de armários numerados de uma academia: todos do mesmo tamanho (mesmo tipo), um nome só
(“armário”) e um número na porta (índice). O primeiro armário é o 0.
⚠  CAI NA PROVA / PEGADINHA
• Homogêneo (vetor: mesmo tipo) × heterogêneo (struct: tipos diferentes).
• O 5º elemento é v[4]; o último de int v[10] é v[9]. v[10] está fora do vetor.
• Vetor estático = tamanho fixo durante toda a execução.

6.3 Arrays multidimensionais (U6-22 a U6-34)
📘  TEXTO DO SLIDE
Um vetor de caracteres pode ser inicializado usando uma string literal: char string1[] = {"primeiro"};

📘  TEXTO DO SLIDE
Estrutura, variável heterogênea ou variável composta heterogênea é o conjunto de variáveis agrupadas
sob um nome único, sendo que estas variáveis podem ser de tipos de dados diferentes. A estrutura serve
para organizar, de forma lógica, algum dado cujo valor é composto por mais de uma variável (ex.: uma data
= dia, mês e ano). Essas variáveis são chamadas elementos ou membros da estrutura. A Estrutura
implementa em C a ideia de registro.
As Estruturas são utilizadas para representar um conjunto de informações logicamente relacionadas.
Exemplos: ficha de cadastro de uma empresa (funcionário); cartão de ponto (funcionário + horários de
entrada e saída); ficha de consultório médico (dados e estado de saúde dos pacientes).
📘  TEXTO DO SLIDE
Onde: a palavra-chave struct inicia a declaração da estrutura; ficha é o nome do identificador; entre as
chaves fica a declaração dos elementos; para cada elemento deve ser especificado o tipo (int matricula).

Declaração da Estrutura (U6-43): as estruturas são definidas com a palavra reservada struct, normalmente
no início do programa (antes da função main) ou em um arquivo separado (.h). Sintaxe: struct

podem ser inicializadas na declaração.

é apenas o modelo dos dados; ainda não foi alocado na memória nenhum espaço, já que nenhuma
variável do tipo da estrutura foi criada. É necessária a declaração de variáveis: struct ficha func1, func2;
— duas estruturas do tipo ficha foram criadas, alocando espaço para os dados de dois funcionários. Sintaxe:
struct identificador_Estrutura nomeVar1, nomeVar2, ..., nomeVarN;

Ponteiros são variáveis que guardam o endereço de outras variáveis. O ponteiro é uma representação
simbólica de um endereço. O C é altamente dependente dos ponteiros; para ser um bom programador
em C é fundamental ter um bom domínio deles.
As variáveis do tipo int guardam inteiros; float guardam números de ponto flutuante; char guardam
caracteres; as variáveis do tipo ponteiro guardam endereços de memória.
Na linguagem C, quando declaramos ponteiros, informamos ao compilador para que tipo de variável
vamos apontá-lo. Um ponteiro int aponta para um inteiro, isto é, guarda o endereço de um inteiro. Se uma
variável contém o endereço de outra, então a primeira (o ponteiro) aponta para a segunda.

Por que utilizamos ponteiros? (U8-09 a U8-11)
🧩  EXEMPLO
Ponteiro é o endereço anotado num post-it. A casa (variável) tem um conteúdo (moradores); o post-it não

📘  TEXTO DO SLIDE
Ponteiros são usados em situações em que a passagem de valores é difícil ou indesejada. Algumas
razões:
• fornecem maneiras com as quais as funções podem modificar os argumentos que recebem;
• para passar matrizes e strings mais convenientemente de uma função para outra, isto é, usar os
ponteiros ao invés de matrizes;
• para manipular matrizes mais facilmente através de movimentação de ponteiros para elas (ou parte

• para criar estruturas de dados complexas, como listas encadeadas e árvores binárias, onde uma
estrutura de dados deve conter referências sobre outra;
• para comunicar informações sobre memória, como na função malloc() que retorna a localização de
memória livre através de ponteiro;
• notação de ponteiros compila mais rapidamente tornando o código mais eficiente.
Uma lista encadeada é uma sequência de structs (os nós) ligados entre si através de ponteiros. Pode ser
acessada através de um ponteiro para o primeiro nó, que é a cabeça da lista. Cada nó contém um ponteiro
que aponta para a struct sucessora. O ponteiro da última struct aponta para NULL, indicando o final da lista.

1.2 Ponteiros e endereços (U8-15 a U8-23)
📘  TEXTO DO SLIDE
Variáveis ponteiro não podem ser usadas antes de serem inicializadas, isto é, enquanto não apontarem
para um endereço de memória válido. Para inicializar podemos atribuir o endereço de outra variável ou
então alocar memória dinamicamente.
Forma geral: tipo_do_ponteiro *nome_da_variável; Exemplo: int *pt. É o asterisco (*) que faz o
compilador saber que aquela variável não vai guardar um valor mas sim um endereço para aquele tipo
especificado.
Existem dois operadores especiais para ponteiros: * e &. O & é um operador unário que devolve o
endereço na memória do seu operando. O operador * é o complemento de &: operador unário que
devolve o valor da variável localizada no endereço que o segue. Os operadores & e * têm precedência
maior do que todos os operadores aritméticos, exceto o menos "-" unário.
Declarações de ponteiros são precedidas do símbolo *: long *x; — x pode conter qualquer endereço de
memória onde está armazenado um inteiro longo. Quando trabalhamos com ponteiros queremos
basicamente: conhecer o endereço de uma variável e conhecer o conteúdo de um endereço.
& (Endereço de): x=&y; significa que o endereço de memória da variável y é colocado em x. * (Valor
apontado por): *x tem o valor da variável apontada por x, ou seja, *x tem o valor de y.
Operador unário é aquele que interage apenas sobre um elemento (+, -, ++ e --): a = -b; a++; &y; *x;
O operador (&) determina o endereço de uma variável; o operador (*) determina o conteúdo de um
endereço.
⚠  CAI NA PROVA / PEGADINHA
• O * tem dois papéis: na declaração diz “é ponteiro”; no uso diz “vá ao endereço”.
• p = 75; muda o endereço (erro lógico); *p = 75; muda o valor da variável apontada.
• int *p; sem inicializar → aponta para lixo; usar *p antes de p=&x é erro.
📘  TEXTO DO SLIDE
Para atribuir um valor a um ponteiro recém-criado poderíamos igualá-lo a um valor de memória. Mas seria
muito difícil saber o endereço de cada variável, pois estes endereços são determinados pelo compilador
na hora da compilação e realocados na execução. Deixamos o compilador fazer este trabalho: para saber
o endereço de uma variável basta usar o operador &.
int count=10; int *pt; pt=&count; — criamos um inteiro count com o valor 10 e um apontador para
inteiro pt. A expressão &count nos dá o endereço de count, o qual armazenamos em pt. Aqui não
alteramos o valor de count, que continua valendo 10.
O código %p usado na função printf() indica que ela deve imprimir um endereço.

📘  TEXTO DO SLIDE
Quando se declara tipo nome[tam1][tam2]...[tamN]; o compilador calcula o tamanho em bytes: tam1 ×
tam2 × ... × tamN × tamanho_do_tipo. Ex.: int x[3][4]; → 3 × 4 × 4 = 48 Bytes. O compilador aloca
esse número de bytes em um espaço livre. O nome da variável que você declarou é na verdade um
ponteiro para o tipo da variável da matriz: ele aponta para o primeiro elemento.
Em C, o nome de um vetor é tratado como o endereço de seu primeiro elemento. int vet[5]=
{1,2,3,4,5}; → vet[0] é 1; *vet é idêntico a vet[0]; a partir desse ponto o endereço é incrementado de 4
em 4 (int de 4 bytes).
Se vet é um vetor, então vet e &vet[0] representam o mesmo endereço. O endereço de qualquer
elemento: &vet[i] é equivalente a (vet + i) — (vet + i) não é uma adição aritmética normal, mas o
endereço do i-ésimo elemento. O valor: vet[i] é equivalente a *(vet + i).
A notação nome_da_variável[índice] → X[4] é absolutamente equivalente a *
(nome_da_variável+índice) → *(X+4). Na linguagem C a indexação começa com zero porque, ao pegar
o primeiro elemento, deseja-se *nome_da_variável, então o índice deve ser zero: *X == X[0].
O nome de um vetor é um ponteiro constante. Podemos também indexar um ponteiro qualquer: int
matrx[10]={1,...,10}; int *p; p=matrx; printf("%d", p[2]); → 3. p[2] equivale a *(p+2).

1.4 Aritmética de ponteiros (U8-31 a U8-39)
⚠  CAI NA PROVA / PEGADINHA
• vet == &vet[0] (verdadeiro). • *(vet+2) == vet[2] (verdadeiro). • *vet+2 é diferente de *(vet+2): o
primeiro é vet[0] + 2 (o * tem precedência maior que +).
• O nome do vetor é ponteiro constante: vet++ é erro; mas p = vet; p++; pode.
• Por isso scanf("%s", nome) não precisa de &.
📘  TEXTO DO SLIDE
A primeira e mais simples operação é igualar dois ponteiros: p1=p2 faz p1 apontar para o mesmo lugar
que p2. Se quisermos que a variável apontada por p1 tenha o mesmo conteúdo da variável apontada por
p2, fazemos *p1=*p2. Depois que se aprende a usar os dois operadores (& e *) fica fácil entender operações
com ponteiros.
Na linguagem C pode-se ter índices negativos: fazem referência às posições de memória antes do vetor.
Ele apenas aloca a memória, ajusta o ponteiro do nome do vetor para o início e, quando você usa os
índices, encontra os elementos requisitados. A varredura sequencial de uma matriz é um dos usos mais
importantes dos ponteiros: usa-se um ponteiro que vai sendo incrementado.
Incremento e decremento: quando incrementamos um ponteiro ele passa a apontar para o próximo valor
do mesmo tipo. Esta é mais uma razão pela qual o compilador precisa saber o tipo de um ponteiro: se você
incrementa um ponteiro char* ele anda 1 byte; se incrementa um double* ele anda 8 bytes. p++; p--;
As operações com ponteiros não são a mesma coisa que operações com o conteúdo das variáveis. Para
incrementar o conteúdo da variável apontada: (*p)++; Soma e subtração de inteiros: p=p+15; ou p+=15; E
para usar o conteúdo 15 posições adiante: *(p+15); A subtração funciona da mesma forma.
Comparação entre dois ponteiros: podemos saber se são iguais ou diferentes (== e !=). No caso de >, <,
>= e <= estamos comparando qual ponteiro aponta para uma posição mais alta na memória (“mais
adiante”): p1>p2.
Há operações que você não pode efetuar num ponteiro: não pode dividir ou multiplicar ponteiros,
adicionar dois ponteiros, adicionar ou subtrair floats ou doubles de ponteiros.

📘  TEXTO DO SLIDE
Em inglês, void quer dizer vazio. Ele nos permite fazer funções que não retornam nada e funções que
não têm parâmetros. Protótipo de função que não retorna nada: void nome_da_função
(declaração_de_parâmetros); — não temos valor de retorno na declaração return, pois ele não é

📘  TEXTO DO SLIDE
Por valor (revisão): na linguagem C, quando chamamos uma função os parâmetros formais copiam os
valores dos parâmetros que são passados. Isto quer dizer que não são alterados os valores que os
parâmetros têm fora da função. Este tipo de chamada é denominado chamada por valor, pois são
passados apenas os valores dos parâmetros e não os próprios parâmetros.
Por referência: outro tipo de passagem ocorre quando alterações nos parâmetros formais, dentro da
função, alteram os valores dos parâmetros que foram passados. Este tipo de chamada tem o nome de
"chamada por referência", porque não se passa para a função os valores das variáveis, mas sim suas
referências (endereços). A função usa as referências para alterar os valores das variáveis fora da função.
Quando queremos alterar as variáveis passadas para uma função, podemos declarar seus parâmetros
formais como sendo ponteiros. Os ponteiros são “as referências” que precisamos. O único inconveniente é
que, quando usarmos a função, teremos de lembrar de colocar um & na frente das variáveis que
estivermos passando.
💡  EXPLICAÇÃO
No slide U8-56 está escrito return num; (erro de digitação — a variável chama num_sqr). No U8-58 o
professor comenta: “o parâmetro formal num_sqr sofre alterações dentro da função, mas a variável
num_main permanece inalterada: é uma chamada por valor”. Já o U8-60 mostra que é possível passar por
referência sem alterar o original: quad=(*pt) * (*pt); return quad; (só lê pelo ponteiro).

O operador de atribuição do C é o =: pega o valor à direita e atribui à variável da esquerda; além disto
retorna o valor que atribuiu. float x=1.5, k=2.3, w=3.5; e if (k==w) — o operador '==' é de
comparação e não de atribuição. O símbolo = não tem o significado usual da matemática; em pseudo-
linguagem é ←. Atribuições inválidas: 1 = a; (constante!) e b + 1 = a; (expressão!).
Atribuição múltipla: var_1 = [var_2 = ...] expressão; — as operações ocorrem da direita para a
esquerda (cuidado com conversões de tipo). Ex.: i = j = k = 1; x = y = 10.0;
Atribuição aritmética: += -= *= /= %=. var += exp ⇔  var = var + exp (idem para os demais). Ex.: i +=
1 e val *= 2.
📘  TEXTO DO SLIDE
Uma instrução de incremento adiciona uma unidade ao conteúdo de uma variável; uma de decremento
subtrai uma unidade. Em C: ++ e --, chamados genericamente de operadores incrementais. ++var,
var++ ⇔  var = var + 1; --var, var-- ⇔  var = var - 1.
Se o operador for colocado à esquerda, a variável é incrementada (ou decrementada) antes de ser usada
em outra operação. Se for colocado à direita, é incrementada depois de ser usada. Os operadores
incrementais têm a mais alta precedência entre todos, superados apenas pelos parênteses.

📘  TEXTO DO SLIDE
Estruturas de controle permitem controlar a sequência das ações lógicas. Basicamente, existem dois tipos:
estruturas de repetição e estruturas de decisão (condicionais). A de repetição permite que um bloco seja
executado repetidamente uma quantidade controlada de vezes; a de decisão permite executar um entre
dois ou mais blocos.
A estrutura if...else é a mais simples estrutura de controle do C; permite executar um entre vários blocos; o
controle é dado por uma condição (expressão lógica ou numérica).
Decisão de um bloco: if(condição){ bloco } — se a condição for verdadeira, o bloco é executado; caso
contrário, não. Dois blocos: if(condição){ bloco 1; } else { bloco 2; }. Múltiplos blocos:
if(condição 1){bloco 1;} else if(condição N){bloco N;} else {bloco P}.

📘  TEXTO DO SLIDE
A estrutura switch...case é uma estrutura de decisão que permite a execução de um conjunto de instruções
a partir de pontos diferentes conforme o resultado de uma expressão inteira de controle. O resultado é
comparado ao valor de cada um dos rótulos, e as instruções são executadas a partir deste rótulo.
switch(expressão){ case rótulo_1: conjunto_1 case rótulo_2: conjunto_2 ... case rótulo_n:
conjunto n [default: conjunto d] } — expressão é uma expressão inteira; rótulos são constantes
inteiras diferentes entre si; o rótulo default é opcional. O fluxo é desviado para o rótulo igual ao resultado
e todas as instruções abaixo deste rótulo serão executadas. Se nenhum rótulo for igual, executa-se o
default. Particularmente útil quando há instruções que se deve executar em ordem, mas podendo começar
em pontos diferentes.
⚠  CAI NA PROVA / PEGADINHA
Sem break, o switch continua executando os cases de baixo (“fall-through”). No menu com ch = getchar()
os rótulos são '1' e '2' (caracteres, que também são inteiros). switch não aceita faixa (case x>5) nem
float.

Em todas as estruturas de repetição existe pelo menos uma expressão que faz o controle: a condição de
controle — expressão lógica ou aritmética cujo resultado pode ser considerado verdadeiro ou falso. C não

por vírgula, mas não mais de uma condição: for(i=0, j=10; i<10; i++, j--).
